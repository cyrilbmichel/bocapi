# Bocapi — bêta gratuite

Application web mobile de lutte contre le gaspillage alimentaire.

## Installation dans GitHub
1. Ouvrir le dépôt `cyrilbmichel/bocapi`.
2. Appuyer sur **Add file** puis **Upload files**.
3. Importer les fichiers contenus dans ce dossier (pas le dossier parent).
4. Valider avec **Commit changes**.

## Fonctions de cette bêta
- Inventaire d’aliments et indispensables configurables.
- Recettes filtrées selon les ingrédients obligatoires disponibles.
- Petit réassort facultatif.
- Préférences et stockage local sur l’appareil.
- Photo avec aperçu et confirmation manuelle des aliments.

## Limites à connaître
La photo ne bénéficie pas encore d’une reconnaissance automatique par IA. Les recettes et filtres alimentaires sont une démonstration et ne garantissent pas l’absence d’allergènes, de traces ou la certification halal. Pas de compte ni synchronisation cloud.

Pour utiliser l’application comme PWA sur iPhone, elle devra ensuite être publiée sur une adresse HTTPS.
